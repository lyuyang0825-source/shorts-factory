# 02 · 短视频：产能已经过剩，稀缺的是“留住人”

## 行业问题不是“做不出来”

2026 年第一季度的公开数据：

- 上线微短剧 **12.8 万部**，其中 AI 微短剧约 **12.2 万部**，占比 **95%**；
- 在播 AI 微短剧 **12.78 万部**，播放破亿的不足 **150 部**，比例约 **0.117%**；
- 2026 上半年新增 AI 短剧破亿率不足 **0.5%**；
- 成本：精品 AI 漫剧约 **4000 元/分钟**，普通约 **1500 元/分钟**；Seedance 类模型 15 秒视频物料成本约 **15 元**，但排队、抽卡、重生成会把“有效成片成本”推高数倍。

结论：**生成不是瓶颈，注意力才是**。95% 的供给在抢不到 1% 的注意力，行业缺的是“3 秒钩子 + 稳定叙事 + 平台适配 + 合规前置”。

## 可被 AI 解决的产品方向

| 方向 | 解决什么 | 本仓库 |
| --- | --- | --- |
| 选题与钩子工厂 | 同一选题生成多个 3 秒开头并排序 | ✅ shorts-factory |
| 分镜与 B-roll 规划 | 把口播拆成镜、给每镜画面任务与时长 | ✅ shorts-factory |
| 多平台改版 | 抖音/视频号/小红书/B站/快手 的时长、标题、封面、话题 | ✅ shorts-factory |
| 合规前置 | 绝对化用语、医疗/金融承诺、免责声明、AI 标识 | ✅ shorts-factory |
| 数据回流迭代 | 用真实完播/跳出数据反过来选钩子 | 路线图 |
| 数字人/口播合成 | 形象、声音、口型 | 未做（接第三方） |

## shorts-factory 的取舍

- 不做“一键生成爆款”的承诺，只做**可执行的生产计划**；
- 六段叙事固定骨架：钩子 → 冲突 → 解释 → 证据 → 反转/建议 → 行动，每段有明确任务与权重；
- 时间轴按 **4.5 字/秒** 全局估算口播自然时长，再按段落权重分配 B-roll 位；字数超出时明确提示“需删减多少字”，而不是硬压语速；
- 字幕按标点切分，过长再按分句切，碎片小于 8 字才合并；
- 封面文案取首个逗号前短语，按像素宽度折行并自动缩字号，避免“熬夜后心慌，什么时候必…”这种截断；
- 合规 7 条：绝对化、医疗承诺、金融承诺、免责声明、封面字数、时长超限、话题数量。

demo 结果：一句“熬夜后心慌，什么时候必须去医院”，产出 **19 镜 / 60.0s / 口播 260 字 / 口播密度 4.3 字/秒 / 阻断 0**，并渲染出 720×1280 样片与 1080×1440 封面。

样片只是**分镜渲染**（色块 + 字幕 + 镜号），用来检查节奏与字幕密度，不是终版成片。

## 怎么衡量

| 指标 | 定义 | 说明 |
| --- | --- | --- |
| 3 秒留存 | 前 3 秒未划走比例 | 钩子的唯一硬指标 |
| 完播率 | 看到最后一帧比例 | 与时长强相关，跨平台不可直接比 |
| 单条生产成本 | 人力分钟 + 模型/渲染费用 | 目标把“有效成片”成本降一个量级 |
| 一次过审率 | 首次提交即通过 | 合规前置的直接收益 |
| 改版耗时 | 一稿改多平台 | 从小时级降到分钟级 |

## 风险与合规

- **医疗/金融内容**：不得承诺疗效、收益、治愈率；必须加免责声明；涉及诊断建议时强制转人工审核。
- **AI 生成内容标识**：按《人工智能生成合成内容标识办法》要求，对合成画面/声音加显式或隐式标识。
- **版权**：B-roll、音乐、字体、数字人形象都要有授权链；AI 生成不等于无版权。
- **平台规则**：不同平台对时长、封面文字、话题数量、导流话术的限制不同，必须按平台校验而不是一套通投。
